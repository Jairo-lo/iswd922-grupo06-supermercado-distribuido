# Resumen de alcance del proyecto

Este documento organiza el alcance técnico del Sistema Distribuido de Gestión de Supermercado del Grupo 06 para ISWD922. Se deriva del texto de referencia y de los anexos PRJ-012-B y PRJ-013 suministrados; no sustituye el Project Charter firmado, que no fue adjuntado.

Se busca mantener productos y existencias consistentes, validar solicitudes viables y no viables contra inventario, integrar operaciones mediante un Gateway y ofrecer recorridos administrativos. El inventario detecta agotamiento, faltantes y excedentes para apoyar ODS 12 meta 12.3. El registro digital de operaciones apoya ODS 8 metas 8.2 y 8.3. No se afirma una reducción de desperdicio medida en campo.

| Paquete | Criterio de aceptación de referencia |
| --- | --- |
| PT-01 | Registros y actualizaciones de inventario consistentes, verificados con escenarios |
| PT-02 | Pedidos viables y no viables tratados con inventario consistente |
| PT-03 | Escenarios integrados superados y operaciones trazables |
| PT-04 | Recorridos vinculados a requisitos y aceptados por el equipo |

Quedan excluidos pagos reales, facturación electrónica o fiscal y logística de envío o reparto. Las pruebas locales constituyen evidencia técnica del incremento, sujeta a revisión cruzada, FCA/PCA y aprobación del equipo. No se declaran patrocinador ni usuario de referencia confirmados: el RBS los mantiene por confirmar o designar.

Marcelo Torres coordina planificación y aprobación interna; Harryson Montesdeoca dirige requisitos y QA; Jairo Quispe controla arquitectura y SCM; Anael Molina implementa PT-01, PT-02 y PT-04 y apoya integración. Tras EVT-REC-01 la capacidad de referencia es 5.5 h semanales por persona, 22 h del equipo. Este trabajo no registra horas humanas ni cambia el calendario académico.
